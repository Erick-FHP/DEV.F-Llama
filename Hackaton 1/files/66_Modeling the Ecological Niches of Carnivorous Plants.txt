\noindent It is time to move beyond exploration and begin building upon the carnivorous plant dataset made available by Harvard University. In this new stage, we aim not only to deepen our understanding of the data, but also to implement a machine learning model capable of performing geospatial identification of the different genera of carnivorous plants worldwide. This direction emerges naturally from the findings of the previous article, where an opportunity was identified to transition from descriptive analysis to predictive modeling.

To achieve this, the original dataset will be enriched with environmental information, specifically 19 bioclimatic variables and elevation data. These variables are sourced from the WorldClim database \cite{clime}, which provides high-quality global climate layers commonly used in ecological and species distribution modeling. The inclusion of these variables allows us to incorporate temperature, precipitation, seasonality, and topographic effects—key factors influencing the ecological niches of carnivorous plants.

The bioclimatic data used in this study correspond to the dataset \texttt{wc2.1\_2.5m\_bio} and \texttt{wc2.1\_2.5m\_elev}, which represents WorldClim version 2.1 at a spatial resolution of 2.5 arc-minutes, equivalent to approximately 4--5 km at the equator. This resolution strikes a balance between global coverage and ecological relevance, making it well suited for large-scale geospatial modeling.

By combining species occurrence records with climate and elevation variables, we create a richer feature space that enables effective feature engineering and sets the foundation for robust machine learning models. This enriched dataset will allow us to explore whether distinct carnivorous plant genera occupy identifiable environmental niches and whether these niches can be learned and classified through data-driven approaches.

\section*{Dataset Enrichment with Bioclimatic and Elevation Variables}

To enable more informative ecological and machine learning analyses, the original carnivorous plant dataset is enriched with environmental variables. Specifically, we incorporate the 19 standard bioclimatic variables and elevation data obtained from the WorldClim v2.1 dataset \cite{clime}. These variables capture key aspects of climate such as temperature, precipitation, seasonality, and extremes, all of which play a fundamental role in shaping species distributions.

The first step consists of downloading the 19 bioclimatic raster layers (\texttt{BIO1}–\texttt{BIO19}) along with the elevation raster, all at a spatial resolution of 2.5 arc-minutes. Each raster represents a global gridded surface from which environmental values can be extracted at specific geographic coordinates.

Once the raster layers are loaded, environmental values are extracted for each occurrence record using the longitude and latitude provided in the original dataset. A nearest-neighbor approach is applied to match each point to the corresponding raster cell. This process results in a single, enriched tabular dataset where each plant record is associated with climate and elevation attributes.

After enrichment, the dataset is exported as a CSV file, which serves as the foundation for subsequent feature engineering and modeling steps. Fortunately, the resulting dataset requires minimal cleaning.

def extract_value(raster, lon, lat):
    return float(raster.sel(x=lon, y=lat, method="nearest").values)

import pandas as pd

for bio_name, raster in bio_rasters.items():
    df[bio_name] = [
        extract_value(raster, lon, lat)
        for lon, lat in zip(df.longitude, df.latitude)
    ]

df["elevation"] = [
    extract_value(elevation, lon, lat)
    for lon, lat in zip(df.longitude, df.latitude)

With the enriched dataset in place, we proceed to the implementation of a machine learning model aimed at classifying carnivorous plant records into the four previously defined genus categories. The objective is to evaluate whether bioclimatic, topographic, and spatially derived features can effectively capture ecological signals that distinguish dominant genera from the aggregated group of rarer taxa.

The following code implements the complete machine learning pipeline used to classify carnivorous plant records into the four defined genus categories based on environmental and spatial features. The workflow is designed to minimize bias, prevent data leakage, and evaluate the model under realistic spatial generalization conditions.

\begin{python}[](style=one-dark){colback=gray!40!black,colframe=blue}
import pandas as pd
import numpy as np
from sklearn.model_selection import GroupKFold
from sklearn.metrics import classification_report, confusion_matrix
from sklearn.feature_selection import SelectFromModel
from sklearn.ensemble import RandomForestClassifier
from catboost import CatBoostClassifier
from collections import Counter
import matplotlib.pyplot as plt

# ---------------------------------------------------
# 1. LOAD DATASET
# ---------------------------------------------------
df = pd.read_csv("Riched Carnivorous Plant.csv")

# ---------------------------------------------------
# 2. FEATURE ENGINEERING
# ---------------------------------------------------
df["dist_equator"] = df["latitude"].abs()
df["dist_meridian"] = df["longitude"].abs()
df["lat_lon_interaction"] = df["latitude"] * df["longitude"]
df["hemisphere_lat"] = (df["latitude"] > 0).astype(int)
df["hemisphere_lon"] = (df["longitude"] > 0).astype(int)
df["temp_range"] = df["bio5"] - df["bio6"]
precip_cols = ["bio12", "bio13", "bio14"]
df["precip_cv"] = df[precip_cols].std(axis=1) / df[precip_cols].mean(axis=1)

# ---------------------------------------------------
# 3. FEATURES AND TARGET
# ---------------------------------------------------
X = df.drop(columns=[
    'id','family','genus','species','study.name','range',
    'num.precision','cat_genus'
])
y = df['cat_genus']

# ---------------------------------------------------
# 4. SPATIAL BLOCKS (GROUPS)
# ---------------------------------------------------
df["lat_block"] = (df["latitude"] // 10).astype(int)
df["lon_block"] = (df["longitude"] // 10).astype(int)
groups = df["lat_block"].astype(str) + "_" + df["lon_block"].astype(str)

# ---------------------------------------------------
# 5. CLASS WEIGHTS (DICT FORMAT)
# ---------------------------------------------------
class_counts = Counter(y)
total = sum(class_counts.values())
class_weights = {cls: total / count for cls, count in class_counts.items()}

# ---------------------------------------------------
# 6. SPATIAL CROSS-VALIDATION
# ---------------------------------------------------
cv = GroupKFold(n_splits=5)
all_reports = []
y_true_all = []
y_pred_all = []

for fold, (train_idx, test_idx) in enumerate(cv.split(X, y, groups)):
    print(f"\n=== FOLD {fold+1} ===")

    X_train, X_test = X.iloc[train_idx], X.iloc[test_idx]
    y_train, y_test = y.iloc[train_idx], y.iloc[test_idx]

    # -----------------------------------------------
    # FEATURE SELECTION INSIDE FOLD (no data leakage)
    # -----------------------------------------------
    selector = SelectFromModel(
        RandomForestClassifier(n_estimators=500, random_state=42),
        threshold="median"
    )
    selector.fit(X_train, y_train)

    X_train_sel = selector.transform(X_train)
    X_test_sel = selector.transform(X_test)

    print(f"Selected features in fold {fold+1}: {X_train_sel.shape[1]}")

    # -----------------------------------------------
    # CATBOOST MODEL
    # -----------------------------------------------
    model = CatBoostClassifier(
        iterations=600,
        depth=6,
        learning_rate=0.05,
        l2_leaf_reg=3,
        verbose=0,
        random_seed=42,
        class_weights=class_weights
    )
    model.fit(X_train_sel, y_train)

    # -----------------------------------------------
    # FOLD PREDICTIONS
    # -----------------------------------------------
    y_pred = model.predict(X_test_sel)

    # Save for overall metrics
    y_true_all.extend(y_test)
    y_pred_all.extend(y_pred)

    # Fold metrics
    report = classification_report(y_test, y_pred, output_dict=True)
    all_reports.append(report)

    print(classification_report(y_test, y_pred))

# ---------------------------------------------------
# 7. AVERAGE MACRO F1 ACROSS FOLDS
# ---------------------------------------------------
f1_scores = [r['macro avg']['f1-score'] for r in all_reports]
print(f"\nAverage Macro F1 across folds: {np.mean(f1_scores):.3f}")

# ---------------------------------------------------
# 8. GLOBAL CONFUSION MATRIX
# ---------------------------------------------------
cm = confusion_matrix(y_true_all, y_pred_all)
plt.figure(figsize=(6,5))
plt.imshow(cm, interpolation="nearest", cmap=plt.cm.Blues)
plt.title("Confusion Matrix - CatBoost")
plt.colorbar()
classes = np.unique(y)
tick_marks = np.arange(len(classes))
plt.xticks(tick_marks, classes, rotation=45)
plt.yticks(tick_marks, classes)
plt.xlabel("Predicted")
plt.ylabel("Actual")
plt.tight_layout()
plt.show()
\end{python}

The pipeline begins by loading the enriched dataset, which already includes bioclimatic variables, elevation, and geographic coordinates. Several additional features are then engineered to capture large-scale spatial structure and environmental gradients, such as distance to the equator, hemispheric indicators, temperature range, and precipitation variability. These derived features complement the raw climate variables and help the model learn ecologically meaningful patterns.

The target variable corresponds to the categorical genus grouping, while predictor variables exclude taxonomic labels and metadata to avoid trivial or indirect leakage of the true class. To further address spatial autocorrelation, the dataset is partitioned into geographic blocks of 10° latitude by 10° longitude. These blocks are used as grouping units in a \texttt{GroupKFold} cross-validation scheme, ensuring that training and test data are spatially disjoint.

Class imbalance is handled by computing inverse-frequency class weights, which are later passed to the classifier. Within each cross-validation fold, feature selection is performed using a Random Forest model, retaining only the most informative predictors based on feature importance. Crucially, this step is executed independently within each fold to prevent information leakage from the test data.

The final classification model is a CatBoost classifier, chosen for its strong performance on tabular data, ability to model nonlinear interactions, and robustness in multiclass settings. Model performance is evaluated using per-fold classification reports, macro-averaged F1 scores, and an aggregated confusion matrix computed across all folds. This setup provides a comprehensive assessment of both overall performance and class-specific behavior under spatially realistic conditions.

The classification model exhibits consistently strong performance across all five spatial cross-validation folds. In each fold, feature selection retained 15 predictors, indicating a stable and informative subset of variables throughout the training process.

Across folds, overall accuracy remains effectively perfect, with macro-averaged F1 scores equal to or very close to 1.00. The average macro F1 score across all folds is 0.999, demonstrating that the model performs equally well across all four genus categories, despite class imbalance. Precision and recall values are uniformly high for all classes, including the least represented category, suggesting that the applied class weighting strategy is effective.

Minor deviations from perfect scores are observed primarily in one of the intermediate categories, where precision and recall occasionally fall slightly below 1.00. However, these variations are minimal and do not substantially impact overall model performance. The aggregated confusion matrix confirms that misclassifications are rare and not systematically biased toward any particular class.

These results indicate that the combination of bioclimatic variables, elevation, and engineered spatial features provides a highly informative representation of the ecological niches associated with the dominant carnivorous plant genera. At the spatial scale considered, the model is able to clearly separate these categories based on environmental conditions alone.

At the same time, the near-perfect performance warrants careful interpretation. Such strong results suggest that genus-level ecological niches are highly distinct in the selected feature space, but they also highlight the importance of validating the model under alternative spatial resolutions or with independent datasets to assess its robustness beyond the current configuration.
